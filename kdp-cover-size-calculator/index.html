How the size is calculated

Width = bleed (0.125") + back cover + spine + front cover + bleed (0.125").
Height = bleed (0.125") + trim height + bleed (0.125").

Spine width depends on the page count and the paper: 0.002252" per page for white paper, 0.0025" for cream and 0.002347" for color. KDP only allows text on the spine when the book has more than 79 pages.

Keep titles and important artwork at least 0.125" inside the trim lines, and spine text at least 0.0625" away from the spine edges. For an exact template with the barcode area, download KDP's cover template for your book.

FAQ

What DPI should a KDP cover be?

300 DPI. The pixel size above already uses it.

Does a hardcover use the same size?

No. Hardcovers have a wrap and hinges, so use KDP's hardcover template instead.
